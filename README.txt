------------------------------------------------------------
1. PROJECT DESCRIPTION
------------------------------------------------------------

MediNova is a modern and responsive healthcare website
designed for a hospital or medical center.

The website provides information about medical services,
departments, doctors, appointments, gallery, and contact
information.

The main goal of MediNova is to provide patients with a
simple, professional, and user friendly online healthcare
experience.

9. HOW TO RUN THE PROJECT
------------------------------------------------------------

No server or database is required for the basic website.

Step 1:
Download or clone the project.

Step 2:
Open the MediNova project folder.

Step 3:
Open:

index.html

in a web browser.

For development, Visual Studio Code with the Live Server
extension is recommended.


------------------------------------------------------------
10. RUN USING VS CODE
------------------------------------------------------------

1. Open Visual Studio Code.
2. Open the MediNova project folder.
3. Install the Live Server extension.
4. Right click index.html.
5. Select "Open with Live Server".
6. The MediNova website will open in your browser.
