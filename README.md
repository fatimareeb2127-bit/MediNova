# MediNova

Modern healthcare website built with HTML, CSS, Bootstrap and JavaScript.

## Features

• Responsive design
• Doctors and departments
• Services
• Appointment page
• Gallery
• Contact page
• Google Maps
• CSS animations

## Pages

Home | About | Services | Departments | Doctors | Gallery | Appointment | Contact

## Technologies

HTML5 • CSS3 • Bootstrap 5 • JavaScript • Font Awesome
